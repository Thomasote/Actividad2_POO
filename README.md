## Compilar y ejecutar

Se requiere un JDK. Desde la raíz del repositorio:

```bash
cd codigo
javac -encoding UTF-8 *.java
java Persona
java Planeta
java Automovil
java PruebaFiguras
java CuentaBancaria
```

Cada programa se ejecuta de forma independiente. Se incluyen los enunciados principales 2.1 a 2.5 del libro *Ejercicios de programación orientada a objetos con Java y UML*, de Leonardo Bermón Angarita.
